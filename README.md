# D&D Store

Full Stack E-Commerce Website built using MERN Stack.

## Features

- User Login & Register
- Product Categories
- Add to Cart
- Wishlist
- Razorpay Payment
- Order Management
- Responsive UI

## Tech Stack

- React.js
- Redux Toolkit
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- Razorpay
